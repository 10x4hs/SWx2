# Grill: Study Trio v3
Date: 2026-09-28

## Intent
세 명이 계획(연·월·주·일)과 실행을 자유롭고 편하게 기록하고, 옵시디언처럼 노트를 연결해 쓰는 앱. 예쁘고 미니멀하되 기능은 넉넉하게.

## Constraints
- 백엔드는 Cloudflare 우선(사용자가 가입 예정). 공개 배포 목적 아님.
- 배경은 실리콘밸리, 폴더 속 기존 작품들의 디자인 문법을 참고.

## Decisions
- 각자 계정 로그인.
- 옵시디언 기능 4종 모두: 링크+백링크, 데일리 노트, 그래프 뷰, 태그+빠른 검색.
- 공개 범위·시간 순서는 답이 없어 추천안 채택 후 "만들기 시작해"로 진행.

## Open
- 추천안(계획 공개/노트 선택 공유, 타임블록+타임라인)이 실제 사용감에 맞는지 첫 사용 후 확인.

## Round 2 — 2026-09-28
- 입장: 가입 없음, **아이디 + 비밀번호** (계정은 `npm run user:add`로 생성). 로그인 화면은 bloom.ai 스타일(구름 + 유리 알약 하나).
- AI: **내 기록 참고**(계획·기록·관련 노트), 기본 모델 **전체**(Gemini + MiMo 나란히 비교), **대화방별 저장**(본인만).
- 키 확인: `sk-…` = Xiaomi MiMo(`api.xiaomimimo.com`), `AQ.…` = Google AI Studio Gemini(`generativelanguage`). 채팅에 노출됐으므로 교체 권장.
- Open: 실제 세 사람 아이디·이름, 배포 시점.
