# Grill: 논문 16편 5일 스프린트 (셋이 같이)
Date: 2026-10-01

## Intent
셋이 10월 5일까지 엣지 비전 파이프라인 논문 16편을 끝낸다. 기준은 "편당 3분 안에, 무슨 문제를 어떤 아이디어로 풀었고 우리 파이프라인의 어디에 쓰이는지 말할 수 있다". 공부 자료는 Claude가 만든다(쉬운 설명, 그림, 영상, 퀴즈). 셋은 서로의 진도를 본다. 다음 주 목표와 이어지는 준비다.

## Constraints
- 마감: 2026-10-05 학습 완료. 오늘이 10-01이라 구축은 하루 안에 끝내야 공부 시간이 남는다.
- 셋 다 같은 16편. 서로의 기록이 보여야 한다.
- 옵시디언은 각자의 것에 들어가야 하고, 10-05 이후에는 없어져야 한다.
- 옵시디언에서는 현황만 본다(체크 + 얼마나 했는지). 가독성이 중요하다.
- 저장소는 셋만 쓰므로 저작권 걱정 없이 원문 그림을 잘라 써도 된다.
- UI/UX는 기존 DESIGN.md(무채색 유리, 색은 차트에만)를 따른다.

## Key decisions
- Decision: 공부 자료는 기존 Dsm-mafia 웹 앱의 새 '논문' 구역(#/papers)에 둔다. Reason: 셋이 이미 계정을 쓰고 있고 기록 공유(D1)가 된다. Alternative considered: 공유 옵시디언 볼트(GitHub/iCloud). 설치, 충돌, 친구 지원 비용이 5일짜리 목표에 비해 크다.
- Decision: 옵시디언에는 '현황 노트'를 넣는다. 사람마다 개인 토큰이 든 웹 임베드(iframe)로 체크, 진도, 셋 비교를 보여 준다. Reason: 체크가 곧 D1에 저장돼 셋이 공유되고, 친구 컴퓨터에 설치할 것이 없다. 10-06부터 서버가 '끝났어요' 화면만 돌려주므로 친구 볼트에서도 사실상 사라진다. Alternative considered: 마크다운 체크박스. 로컬에만 남아 공유가 안 된다.
- Decision: 체크 단위는 논문마다 3단계(① 읽기 ② 퀴즈 ③ 3분 설명)로 총 48칸이다. Reason: '3분 설명' 기준을 그대로 측정한다.
- Decision: 내 볼트 ENGLISH-OS를 STUDY-OS로 바꾸고 최상위를 '논문 공부 / 영어 공부' 두 구역으로 나눈다. 영어 자료는 '영어 공부/' 아래로 옮기고 경로 링크, dataview, 설정, 스크립트를 함께 고친다. Reason: 사용자가 영어를 최상위 개념으로 묶으라고 요청했다.
- Decision: 10-06 00:05 KST에 launchd가 내 볼트의 '논문 공부/'를 휴지통으로 옮긴다(영구 삭제 대신 복구 가능). 웹 구역은 10-06부터 메뉴에서 빠지고 결과 요약만 남는다.
- Decision: 영문 원문 PDF는 arXiv 링크로 연결하고, 한국어 번역 PDF 6개는 앱에서 직접 연다. Reason: 원문 3개가 Workers 에셋 한도(25MiB)를 넘는다.

## Surfaced assumptions
- 10-06은 16편을 설명해야 하는 자리(미팅이나 발표)다. 사용자가 추천안을 수락했을 뿐 직접 말하지는 않았다.
- 친구들은 옵시디언을 쓰고, 노트 하나(.md)를 자기 볼트에 넣을 수 있다.
- 16편은 RGB+열화상 → 탐지 → 추적 → 시간 모델 → 증류 → INT8/RKNN 배포로 이어지는 하나의 파이프라인을 위한 것이다.

## Correction (2026-10-01, 2차)
- '옵시디언'은 **앱 안의 노트(옵시디언식 노트·그래프)**를 뜻했다. 진짜 옵시디언 볼트(STUDY-OS)에 한 작업은 사용자 요청으로 그대로 둔다.
- Decision: 셋의 앱 노트에 각각 `📄 논문 공부` 페이지 트리를 넣는다. 맨 위에 실시간 현황판 블록(셋 진도, 체크 가능)을 두고, 아래에 16편 하위 페이지(날짜별, [[링크]]·#태그로 그래프 연결)를 둔다. 하위 페이지 내용은 각자만 본다. Reason: 사용자가 A안을 골랐다. Alternative considered: 셋이 같이 쓰는 공유 구역.
- Decision: 셋 모두에게 `🇺🇸 영어` 페이지 트리(ENGLISH-OS 자료 노트)를 넣는다. 개인 기록(매일 기록, 내가 막힌 표현, 내 진도)과 서식·첨부는 뺀다. 개인 기록은 앱의 영어 탭에 이미 있다. Reason: "각자 다 개별로". 개인 기록을 친구에게 복사하지 않기 위해서다.
- Decision: 넣기는 스크립트(`scripts/study-notes-seed.mjs`)로 원격 D1에 직접 한다. 기존 같은 제목의 노트는 덮어쓰지 않는다. 10-06 크론이 논문 트리(하위 포함)를 지운다.
