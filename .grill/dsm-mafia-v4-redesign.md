# Grill: Dsm-mafia v4 — 영상 기반 재디자인 + AI 정리/생성
Date: 2026-09-28

## Intent
지금 디자인이 어색하고 차트가 안 읽힌다. 준 영상 4개(blackray-a CIAO, blackray-b EDOLUS, aianykey Second Brain, igloo)의 요소·글씨체·모션·텍스처를 판단해 다시 입히고, AI가 옵시디언처럼 노트를 정리하고 새로 만들어 주길 원한다.

## Key decisions
- Decision: 링은 **흘러간 시간(흐린 호) + 목표 달성(밝은 호)** 을 겹쳐 그린다. Reason: 올해가 D-94인데 링이 텅 비어 보임 — 목표가 없어도 시간은 차 있어야 함. 둘 사이 틈 = 밀린 만큼. Alternative considered: 시간만 / 달성만(기존).
- Decision: 차트는 **동심원 링 4개 유지, 칸 분할 없앤 매끈한 호 + 링 끝에 숫자 라벨 + 옆에 큰 숫자 표**. Reason: 가독성. Alternative considered: 가로 막대, 큰 링 1 + 작은 링 3.
- Decision: **UI는 무채색, 데이터만 네온**(링 달성 호, 세 사람 구분색, 그래프 클러스터). Reason: Second Brain 영상의 문법, 기존 무채색 원칙과 절충. Alternative considered: 완전 무채색, 포인트 컬러 하나.
- Decision: AI는 **정리 + 생성** 둘 다. 정리 = 내 노트를 읽고 #태그·[[링크]]·주제 분류를 **노트에 직접 써넣고** 주제별 목차(MOC) 노트를 만든다. 생성 = 채팅/주제에서 개념 노트 여러 개를 만들어 서로 링크해 저장. Reason: "옵시디언 같은 UI 정리도 해주고 생성도 해주는" 것. Alternative considered: 진짜 Obsidian 볼트 내보내기(기각), 원문 보존 + 그래프에만 표시(기각 — 사용자가 직접 써넣기 선택).

## 영상 판정 (Claude 결정)
- 가져옴: 검은 배경 + 가운데 스포트라이트 비네팅(CIAO), 필름 그레인, HUD 모서리 괄호·`// LABEL` 모노 라벨(EDOLUS), 큰 그로테스크 제목 + 작은 모노 수치(Second Brain), 네온 노드 클러스터, 부유/등장 모션.
- 버림: 사막 사진 배경, 마젠타 원색, 전면 흰 점토(igloo) — 4개 중 3개가 다크.

## Surfaced assumptions
- AI가 노트에 써넣는 부분은 원문과 섞이지 않게 노트 끝의 표시된 구역에만 쓰고, 다시 돌리면 그 구역만 교체한다(중복 방지).

## Open questions
- 라이트 모드 유지 여부 — 이번엔 다크 기본으로 만들고 라이트는 동작만 유지.

## Round 2 — 2026-09-29 (v7: Apple glass + 색)
- 피드백: 너무 흑백이라 별로, 가독성 낮음, 사용법을 모르겠음, 왼쪽 툴바가 이상함, 잔디는 초록으로.
- Decision: **로그인은 황금빛 구름 사진을 컬러 그대로**(흑백 필터 제거). 앱 배경도 같은 사진을 흐리게 깔고 그 위에 유리. Reason: 사용자가 사진 지정 + 유리는 뒤에 색이 있어야 살아남.
- Decision: **Apple 글래스모피즘을 조금**(반투명 + 강한 blur·saturate, 얇은 흰 테두리, 위쪽 하이라이트) + **Apple 시스템 색을 약간**(파랑 = 주 버튼·선택, 링 = 주황/초록/파랑/분홍, 잔디 = 초록). Alternative considered: 노을 톤 전용 팔레트, 네온 유지, 파스텔(모두 사용자가 직접 방향 제시로 대체).
- Decision: **툴바는 아이콘만, 아이폰 앱 아이콘처럼** 색 있는 둥근 사각형 + 한눈에 뜻이 보이는 그림(오늘 = 오늘 날짜 달력, 노트 = 노란 메모지, AI = 반짝임, 타이머 = 스톱워치). 이름은 마우스를 올리면. 모바일은 아래 Dock.
- Decision(Claude): 사용법 — 홈에 '시작하기' 3단계 안내(할 일 → 목표 → 노트·AI 정리), 글자 대비와 최소 크기 올림.
- 사용자 성향: 객관식 질문보다 자기 말로 방향을 주는 걸 선호. 오타는 문맥으로("아이폰" = 아이콘).

## Round 3 — 2026-09-29 (v8)
- 피드백: 아이디 누를 때 모션 어색 → 처음 모습 유지 / 툴바 이름표가 가려짐 / 색 촌스러움 → **차트에만 약간 색** / 계획에 맞춰 차트가 바뀌게 / Second Brain을 옵시디언처럼 가독성 있게.
- Decision: 로그인 포커스 시 화면 줄어듦·흐림 제거(입력칸 테두리만 밝게). 툴바 z-index 올림.
- Decision: UI 무채색(주 버튼 = 흰색/검정, 아이콘 = iOS 다크 모드식 무채색 타일, 배경 사진 흑백), 차트 색은 채도 낮춘 `--c-*`.
- Decision: 링 = 목표 하나당 칸 하나(이룬 건 채움), 오늘 = 24시간 시계 위 시간표 블록, 흘러간 시간 = 바깥 얇은 선.
- Decision: 그래프 = 옵시디언식 2D(제목 표시, 주제 그룹 색, 설정 패널). 3D(Three.js)는 제거.

## Round 4 — 2026-09-29 (AI 키 · 차트 넘기기 · 배포)
- Intent: 전체 차트 한 장에 4기간이 몰려 가독성이 떨어짐 → **기간별로 한 장씩 넘겨 보는 차트 4장**(① 전체 ② 한 달 ③ 한 주 ④ 하루). 전부 차트로(목록 X).
- Decision: 배포 = **Cloudflare Workers + D1** (이미 그 구조, 무료). Alternative considered: Vercel(서버·DB 새로 짜야 해서 기각).
- Decision: AI = Gemini(새 키) + **Groq**(gpt-oss-120b) + **Cohere**(command-a 채팅, embed-multilingual 임베딩으로 비슷한 노트 찾기). MiMo 유지. 키는 `.dev.vars`/Worker secret에만.
- Decision: 작업은 **서버 에이전트 / 화면 에이전트**로 나눠 병렬(파일 경계: 서버 = src·migrations·scripts·wrangler·README 배포 부분·views/ai.js / 화면 = home·ringhud·새 차트 파일·styles·api.js).
- Surfaced assumption: 공개 주소에 PASSWORDLESS=1 이면 아이디만 알면 누구나 들어옴 → **배포본은 비밀번호 필수**, 로컬만 아이디 로그인 유지.
- Open: 채팅에 노출된 키 3개는 동작 확인 후 재발급 권장.
