# 원문 그림 번역 (`public/papers/content/<id>.figtr.json`)

그림 안의 영어(그림 제목 · 설명 · 칸 이름 · 축 · 범례)를 한국어로 옮겨요. 쉽게 읽기와 논문 페이지에서 그림 아래 "한국어로 보기"를 누르면 나와요.

```json
{
  "f2.jpg": {
    "title": "그림 2: 여러 융합 방식 비교",
    "caption": "(a) 입력 융합은 센서마다 다른 연산으로 입력을 합쳐요 [15], [16]. (b) 특징 융합은 채널 어텐션으로 특징을 한 방향으로만 합쳐요 [8], [9]. (c) 우리의 상호작용 융합은 양방향 교차 센서 특징 보정과 시퀀스-투-시퀀스 교차 어텐션을 넣어, 센서끼리 폭넓게 주고받게 해요.",
    "labels": [
      { "en": "(a) Input fusion", "ko": "(a) 입력 융합" },
      { "en": "(b) Feature fusion", "ko": "(b) 특징 융합" },
      { "en": "(c) Interactive fusion", "ko": "(c) 상호작용 융합" }
    ],
    "terms": [ { "en": "cross-attention", "ko": "교차 어텐션", "easy": "한쪽이 다른 쪽에서 필요한 정보를 골라 가져오는 계산" } ]
  }
}
```

- 키 = `public/papers/fig/<id>/` 안의 파일 이름 (jpg/png 만, diagram.svg 는 이미 한국어라 빼요).
- `title`: 그림 번호와 제목 ("Fig. 2: …" → "그림 2: …"). 그림에 캡션이 없으면 그림이 보여 주는 것을 한 줄로.
- `caption`: 그림에 찍힌 영어 설명 전체를 **빠짐없이** 자연스러운 한국어로 (문헌 번호 [15] 는 그대로). 잘려서 안 보이는 부분은 옮기지 말고 끝에 "(그림에서 잘림)".
- `labels`: 그림 안에 보이는 영어 글자 — 칸 이름, 화살표 글씨, 축 이름, 범례, 표 머리글 — 를 위에서 아래, 왼쪽에서 오른쪽 순서로. 숫자만 있는 것, 모델 이름(ViT-B, YOLOv10-S 같은 고유명)은 빼요. 같은 글자는 한 번만.
- `terms`: 번역해도 어려운 전문용어 2~5개를 중3 눈높이 한 줄 풀이로.
- 번역은 정확하게. 모르는 약어는 원문 그대로 두고 괄호에 풀이.
