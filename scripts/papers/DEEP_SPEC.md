# 자세히 읽기(deep) — 규칙서 (에이전트용)

이미 있는 요약 자료(`public/papers/content/<id>.json`)는 건드리지 말고, **별도 파일** `public/papers/content/<id>.deep.json` 을 만들어요.
목표: 학생이 "이 논문이 **어떻게 작동하고 왜 그렇게 만들었는지**"를 원문을 안 펴 봐도 알 만큼 **깊고 빠짐없이**. 분량 제한 없음(보통 6,000~15,000자). 쉬운 한국어 해요체, 비유 먼저, 용어는 처음에 풀어서. 숫자는 원문 표·본문에서 확인한 것만.

입력: 영어 원문 PDF(PyMuPDF 로 **전체** 읽기 — 부록은 핵심만), 한국어 해설 md, 번역 PDF(있으면).

## 절 나누기
원문 목차를 **그대로** 따라가요(서론 · 관련 연구 · 방법의 소절 하나하나 · 실험 설정 · 주요 결과 · 소거 실험(ablation) · 분석/시각화 · 한계 · 결론). 관련 연구는 짧게 묶어도 되지만 **방법과 실험 소절은 하나도 빼지 말아요**. 부록은 "본문 이해에 필요한 것"만 한 절로.
각 절 body 는 최소 400자, 방법 절은 800자 이상. "자세한 건 원문 참고"로 넘기지 말고 **여기서 설명**해요.
