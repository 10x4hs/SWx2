# 홈 오늘 링에서 끌어서 계획 넣기 — 설계

2026-10-15 · 승인: 사용자 ("이대로 만들고 PR까지")

## 무엇을
홈(#/)의 오늘 링 — 하루 쪽 큰 24시간 시계, 전체 쪽 링 다섯 개 중 '오늘' — 위에서 바로 오늘 계획을 넣어요.

1. 마우스를 대면: 링을 가로지르는 가는 선 + 그 시각(5분 단위, 예: 14:05).
2. 누른 채 링을 따라 끌면: 누른 자리부터 조각이 5분씩 자라요. 시계 가운데에 `14:00 → 15:25` / **+85분** / `1시간 25분`, 끝 쪽엔 끝 시각. 반대로 끌면 시작이 앞당겨져요. 0시~24시 안에서만.
3. 놓으면: 그 자리에 이름 칸. Enter 저장 · Esc 또는 바깥 누르기 취소. 저장하면 조각이 종류 색(이름으로 짐작)으로 놓여요.
4. 끌지 않고 누르기는 지금 그대로 (빈 링 → 하루 계획표, 조각 → 계획 카드).
5. 컴퓨터(마우스)에서만, 내 차트에서만. 폰 · 친구 차트는 그대로.

겹치는 계획도 넣을 수 있고(가운데에 "겹침: …" 한 줄), 지난 시간에도 넣을 수 있어요.

## 어떻게
- **새 파일 `public/js/ring-drag.js`** — 두 원이 같이 써요. 차트 SVG 에 `data-dial="cx cy ri ro pad cr"`(viewBox 단위: 중심, 링 띠 안·바깥 반지름, 잡는 여유, 가운데 빈 원 반지름)가 있으면 그 위에서 움직여요. SVG 안에 끌기 층(`<g class="rd">`)을 얹고, 끄는 동안엔 그 층의 선 · 조각 · 글자만 고쳐요 — 차트를 다시 그리지 않아요.
- 마우스 좌표 → SVG 좌표는 `getScreenCTM().inverse()`, 각도 → 분은 12시 방향에서 시계 방향 0~1440. 한 바퀴를 넘는 끌기를 위해 각도 변화량을 이어 붙여요.
- 6px 넘게 움직여야 끌기로 봐요. 끌기 뒤에 오는 click 은 캡처 단계에서 막아서 페이지 이동이 안 일어나요.
- **`charts/day.js` · `ringhud.js`** — `data-dial` 만 붙여요.
- **`views/home.js`** — 끌기를 붙이고, 저장은 기존 `POST /plans { scope:"day", period, text, start, mins }`. 끄는 중 · 이름 칸이 열린 동안엔 1분마다 하는 다시 그리기와 `trio:changed` 다시 그리기를 미뤘다가 끝나면 한 번 그려요.
- 서버 · DB 변경 없음.

## 고른 방법과 버린 방법
- 고름: SVG 끌기 층만 고치기 — 끊김 없고 차트 코드는 거의 그대로.
- 버림: 움직일 때마다 차트 전체 다시 그리기(깜빡임) · 캔버스 겹치기(좌표를 두 번 맞춰야 해서 어긋남).

## 검사
- e2e: 하루 쪽 · 전체 쪽 각각 실제 마우스로 대기(선 · 시각) → 끌기(+분 글자) → Enter 저장(서버에 계획) → Esc 취소 → 끌지 않고 누르면 그대로 이동 → 친구 차트 · 폰 크기에선 선이 안 떠요.
- `npm test`.
