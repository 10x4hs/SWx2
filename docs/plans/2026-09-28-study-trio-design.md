# Study Trio v3 — 설계 문서
Date: 2026-09-28 · Status: 승인("만들기 시작해", 추천안 채택)

## 목표
세 명이 각자 계정으로 들어와 **연·월·주·하루 계획을 자유롭게 세우고 실행을 기록**하며,
옵시디언처럼 **마크다운 노트를 [[링크]]로 엮어** 공부 지식을 쌓는 개인용 웹앱.

## 결정 사항
| 항목 | 결정 | 이유 |
|---|---|---|
| 호스팅 | Cloudflare Workers + D1 + Static Assets | 무료, 카드 불필요, 슬립 없음, `wrangler dev`로 오프라인 개발 |
| 로그인 | 각자 계정 · 초대 코드 가입 · PBKDF2 해시 · HttpOnly 세션 쿠키 | 사용자 선택 |
| 공개 범위 | 계획·기록·진행률은 셋이 서로 봄(수정은 본인만). 노트는 기본 비공개, `공유` 토글 | 추천안 채택 |
| 시간 순서 | 하루 계획 = 06–24시 타임블록 / 한 일·메모 = 시간순 타임라인 | 추천안 채택 |
| 옵시디언 기능 | [[위키링크]]+백링크, 데일리 노트, 그래프 뷰, #태그 + ⌘K 검색 | 사용자 선택(4개 전부) |
| 프론트엔드 | 빌드 없는 바닐라 ES 모듈, marked + DOMPurify 벤더링 | 단순함, 빌드 단계 없음 |
| 디자인 | 실리콘밸리 사진(안개 위 금문교) + 유리 패널 + 헤어라인 + 그레인. Geist/Pretendard/Geist Mono/Instrument Serif | 폴더 작품들의 공통 문법 계승 |

## 화면
- **오늘**: 시간 블록 플래너(시간순) · 실행 타임라인(지금 시각으로 기록) · 데일리 노트 · 오늘 점수 · 어제 못 한 일 가져오기
- **계획**: 연/월/주/일 탭, 이전·다음 기간 이동(미리 계획 가능), 완료율 vs 기간 경과, 1년 히트맵
- **노트**: 목록/태그 · 편집⇄미리보기 · [[자동완성]] · 백링크 · 공유 토글
- **그래프**: 노트 연결 force 그래프, 소유자 색
- **우리 셋**: 멤버별 연·월·주·오늘 진행률과 오늘 타임라인
- 공통: ⌘K 명령 팔레트, 집중 타이머(완료 시 타임라인에 기록), 연속 달성일(streak)
