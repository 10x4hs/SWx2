# v7 — Notion 식 노트 편집기 + 그래프에서 연결 (2026-09-29)

요청: 그래프에서 점을 누르고 다른 점을 누르면 연결, 두 번 누르면 들어가기. 편집기는 Notion 처럼(H1 버튼, URL, 페이지, 내장 AI). 옵시디언 느낌. 점만 있는 그래프 UI 개선. "만드는 중…" 버튼 넘침.

## 결정
- **연결은 본문에 남긴다**: 그래프에서 이으면 첫 노트 본문 끝 `## 연결` 아래 `- [[제목]]` 한 줄. 별도 연결 표 없음 — 기존 `note_links` 색인·백링크·AI 정리가 그대로 동작. 끊기는 그 줄(또는 본문 속 `[[제목]]` → 글자만)을 지움.
- **편집기는 마크다운을 그대로 저장**: 블록 ↔ 마크다운 변환(`parseBlocks` / `serializeBlocks`). 예전 노트, `[[링크]]`, `#태그`, `<!-- ai:start -->` 구역, MOC 표시가 그대로. 표·HTML 은 "그대로" 블록으로 글자만 고침. 원문 탭(마크다운 textarea)도 남김.
- **페이지** = `notes.parent_id`(마이그레이션 0010). 노트 안 `/페이지` 또는 아래 "＋ 페이지" → 하위 노트 생성 + 본문에 `[[제목]]` 한 줄(페이지 카드). 위에 경로(부모 › 자식). 부모가 지워지면 최상위로.
- **편집기 안 AI**: `POST /api/ai/ask { note_id, question, context }` → `aiText`(대화방과 같은 회사 순서)로 300단어 이내 마크다운 답 → `<!-- ai:start -->**Q.** 질문\n\n답<!-- ai:end -->` AI 블록으로 그 자리에. "본문으로" 누르면 일반 블록으로 풂. 답을 만들 때 노트 본문(1만 2천 자까지)만 보냄 — 다른 노트·일기는 안 봄.
- **그래프 조작**: 클릭(280ms 안에 두 번이면 더블클릭) → 고르기(숨 쉬는 고리 + 아래 띠 + 마우스로 점선). 고른 채 다른 점 → 연결(없는 노트가 골라졌으면 방향 반대로 적음). 같은 점 → 취소. 빈 곳/Esc → 취소. 선 클릭 → 팝오버(첫 노트 열기 · 연결 끊기). 페이지 트리는 점선, 끊기 없음. 클릭으로는 물리를 안 데움(점이 안 움직여야 두 번째 클릭이 맞음).
- **그림**: 배경 안개, 점마다 바깥 빛 + 알맹이 하이라이트, 굽은 선(이웃은 두 색 그라디언트), 가리킨/고른 점 제목 뒤 판. 색 규칙 유지(주제색만, UI 무채색, AI 는 보라 테두리).

## 남은 것
- 블록 끌어서 순서 바꾸기(드래그) 없음 — ⋮⋮ 메뉴는 바꾸기·지우기만.
- 목록 들여쓰기(Tab) 없음. 표는 원문 탭에서만 고침.
- 편집 중 `**굵게**` 처럼 직접 친 기호는 다른 블록으로 갈 때 서식으로 바뀜.

## v7.1 (같은 날 저녁) — 사용자 피드백 반영
- "디자인이 더 별로" → 그래프의 빛·안개·굽은 선·펄스 고리·글자 판을 모두 뺌. 단색 점 + 곧은 얇은 선. 선 위에 올리면 ✕ 버튼(끊기).
- 편집기 위 도구 막대 제거, `/` 메뉴와 긁었을 때 작은 도구만.
- "지우거나 드래그가 한 줄씩만 됨" → 블록마다 contenteditable 이던 구조를 **문서 하나가 contenteditable** 로 바꿈(`.nb-doc`). 블록은 `.blk[data-type]` 자식. 여러 줄 선택·삭제·복사가 브라우저 기본으로 됨. 목록 점·번호·체크 상자는 CSS(::before, counter)로 그려서 DOM 에 위젯이 없음.
- 왼쪽 ⋮⋮ 를 끌어 블록 순서 바꾸기.
- 노트 목록(찾기 패널) 접기: `.notes.list-hidden`, localStorage `trio-nl`.
- 페이지 이동 렉: 목록·노트를 동시에 받기(직렬 → 병렬), 본 노트 캐시(`noteCache`)로 먼저 그리고 새로 받기, `[[링크]]` 클릭은 목록에서 id 를 찾아 resolve 요청 생략.
