# 둘이 같이 보는 일기 페이지 — 설계

2026-10-16 · 승인: 사용자 ("이대로 만들고 배포까지")

## 무엇을
- 독에 '일기' 아이콘 → `#/diary`. 일기 모임(HSK · GYK)에게만 보이고, 모임 밖(CHJ)은 서버가 403. CHJ 는 지금처럼 캘린더 안에서 자기 일기만.
- [내 일기 | 상대 일기] 탭 + ‹ 날짜 ›. 내 일기는 쓰기(기분 · 글 · 자동 저장) + **공개 · 비공개** 스위치, 상대 일기는 읽기만. 탭 아래 그 사람의 올해 잔디(비공개 날은 빗금), 옆에 지난 일기.
- 지금까지의 일기는 모두 비공개로 시작(‘나만 본다’고 쓴 글이라서). 새 일기는 편집기에서 기본 공개. 지난 일기도 날마다 직접 공개 가능. 처음 열 때 안내 한 번.
- 비공개 날은 상대에게 자물쇠만 — 서버가 날짜와 비공개 표시만 보내고 기분 · 글은 아예 보내지 않아요.
- 모임 사람이 옛 주소(`#/calendar/diary/날짜`, 올해 잔디 칸, `#/diary`)로 오면 새 페이지로.

## 어떻게
- 마이그레이션 0051: `diaries.shared`(기존 0), `users.diary_circle`(아이디 hsk · gyk 만 1).
- 서버 `src/diary.js`: `GET /diary/circle`, `GET /diary/of?user&day`, `/diary/of/days`, `/diary/of/list` — 둘 다 모임일 때만, 남의 비공개 행은 `{ day, private: true }`. `PUT /diary` 는 `shared` 를 받고, 안 보내면 새 일기 비공개 · 있던 일기 그대로(페이지 · MCP 로 쓴 일기가 실수로 열리지 않게). 세션 사용자에 `diary_circle`.
- 서비스 워커: `/api/diary*` 는 저장하지 않아요 — 상대가 비공개로 바꾼 뒤에도 저장해 둔 공개 글을 먼저 보여 주던 문제, 남의 기기에 일기가 남는 문제.
- 화면: `views/diary-room.js`(새 페이지), `diary.js` 편집기에 `share` 옵션(스위치), 독 메뉴 `when(me)`.

## 검사
e2e ⑱: 모임 독 아이콘 · 탭 2 · 새 일기 공개 → 친구가 읽음 · 비공개면 `{ private }` 만(기분 · 글 없음) · 지난 일기 비공개 · 친구 탭 읽기 → 비공개 후 새로 고침해도 자물쇠 · 모임 밖 403(모임 · 남의 일기 · 남이 모임 밖 일기) · 아이콘 없음 · `#/diary` → 캘린더.
